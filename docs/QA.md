# FloraMesh QA Test Matrix & Regression Guide (`docs/QA.md`)

This document establishes the Quality Assurance test suites, regression test protocols, and verification records for all 44 confirmed code issues identified during the forensic audit of the FloraMesh storefront.

## 2. Regression Testing Script (`tests/`)
Dedicated regression test pages executable over `file://` protocol:
1. `tests/escape.html`: Injects `<img onerror>` attack vectors via URL parameters, search queries, gift notes, and cart local storage.
2. `tests/validate-products.html`: Validates product data schema v2 integrity (slug uniqueness, price parity, variant coverage, image links).
3. `tests/regression-suite.html`: Automated browser test runner verifying quantity clamping, shipping exemption rules, and accordion toggling.
