Accessibility Statement

FloraMesh is committed to ensuring our botanical storefront, IoT telemetry dashboards, and planting resources are fully accessible to every user, including those using screen readers, keyboard navigation, and magnification software.

1. Conformance Standard

This website aims to conform with the Web Content Accessibility Guidelines (WCAG) 2.2 Level AA. These guidelines specify how to make web content more accessible to people with disabilities, and user-friendly for everyone.

2. Key Accessibility Features Implemented

  • Semantic Landmarks: Every page uses HTML5 semantic tags (<header>, <nav>, <main>, <footer>, <dialog>) to allow effortless landmark navigation.
  • Skip to Main Content: A dedicated keyboard skip link is the first focusable element on every storefront page.
  • High-Contrast Dual Themes: Both Heritage Cream and Midnight Grove themes exceed the 4.5:1 contrast ratio requirement for normal text and 3:1 for graphical UI elements and form boundaries.
  • Focus Management & Trapping: Modal dialogs, the search command palette, and mobile sheets capture focus, maintain inert backdrops, and return focus to triggering buttons upon dismissal.
  • Reduced Motion Support: The storefront respects the system (prefers-reduced-motion: reduce) query, disabling non-essential transitions and animations.
  • Keyboard Navigable Galleries: Product image lightboxes and carousels support Arrow keys and Escape without trapping focus or firing inside text inputs.
  • Descriptive Typography: Text scales cleanly up to 200% zoom without truncating or overlapping content.

3. Assistive Technology Compatibility

FloraMesh is tested across modern desktop and mobile browsers (Chrome, Firefox, Safari, Edge) in conjunction with screen reading software including NVDA, VoiceOver, and TalkBack.

4. Feedback & Assistance

We welcome your feedback on the accessibility of FloraMesh. If you encounter any barriers or need assistance placing an order, please email our accessibility team directly at hello@floramesh.pk.
